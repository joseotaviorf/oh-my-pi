# unstable-srat

Plugin de exemplo distribuído pelo marketplace `bi-etl-ejuice`.

## Uso

Digite o comando abaixo no Claude:

```
/unstable-srat
```

O agente responderá:

```
hello world
```

```
unstable-srat/
├── .claude-plugin/
│   └── plugin.json          # Metadados do plugin
├── commands/
│   └── unstable-srat.md     # Slash command /unstable-srat
└── README.md
```
