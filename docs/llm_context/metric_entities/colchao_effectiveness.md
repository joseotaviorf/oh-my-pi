## Overview

**Colchão Effectiveness** measures recovery performance specifically on invoices under an active, actionable negotiation agreement (the "colchão de acordos") within the T2 overdue portfolio — the segment of the portfolio that has already been negotiated and has an installment currently due, as opposed to the directly-collectable segment tracked by the Collections Actions Funnel / Net Recovery entities. This entity covers two Health Metrics: **Colchão Effectiveness** (the absolute amount recovered from on-time negotiated installments) and **% Colchão Effectiveness** (that amount expressed as a percentage of the negotiated wallet due in the same population).

## Scope

**Included**: invoices under an active, actionable negotiation agreement (`actionable_regularized_portfolio = TRUE`) in `sandbox.t2_fact_overdue_portfolio_timeline`.

**Excluded**: directly-collectable invoices without active negotiation (the Net Recovery / Collections Actions Funnel population); invoices under a non-actionable regularized negotiation, i.e. an installment not yet due (`non_actionable_regularized_portfolio = TRUE`).

## Calculation

```
Colchão Effectiveness   = SUM(on_time_negotiation_installment_recovery)
% Colchão Effectiveness = SUM(on_time_negotiation_installment_recovery) / SUM(due_amount)
```

`on_time_negotiation_installment_recovery` is documented on the source T2 entity as recovery attributed to negotiated installments **paid on time** under an active (non-cancelled) parent negotiation — worth confirming with the requester whether late-paid negotiated installments should also count toward this metric, or whether the on-time restriction is intentional.

### Canonical Filter

Apply on `sandbox.t2_fact_overdue_portfolio_timeline`:

```sql
actionable_regularized_portfolio = TRUE
```

**Note**: the example production query this entity was built from also added `status_evic = 'EM COBRANCA'` (excluding eviction-stage cases). Confirmed by the requester to be **specific to that particular chart, not a mandatory part of the official canonical filter** — treat `status_evic = 'EM COBRANCA'` as an optional refinement, not baked into this entity's core definition, unless told otherwise.

### Nuances

- **Business-day alignment**: apply `is_last_business_days = TRUE` when comparing by `business_day` across months, same convention as the sibling entities on this table.
- **Rolling window convention**: the example production queries scope to a trailing ~12 month window — a performance convention, adjustable per analysis.
- **Mutually exclusive with Net Recovery**: a given invoice is either in the directly-collectable segment (Net Recovery) or the regularized/negotiated segment (this entity), never both at the same `dt_reference` — `collectable_delinquent_portfolio` and `actionable_regularized_portfolio` do not overlap.

## Dos and Don'ts

**Do:**
- Apply `actionable_regularized_portfolio = TRUE` as the canonical filter.
- Apply `is_last_business_days = TRUE` when comparing by `business_day` across months.
- Keep this entity separate from Net Recovery (different, complementary population) and from the Collections Actions Funnel's "% Acordo" (a conversion rate, not a currency amount).

**Don't:**
- Don't sum `due_amount` / `on_time_negotiation_installment_recovery` across multiple `dt_reference` values, or group by `business_day`, without first collapsing the daily fan-out.
- Don't assume `status_evic = 'EM COBRANCA'` is a mandatory part of the canonical filter — it was chart-specific.
- Don't assume the older and newer "Colchao Effectiveness" Superset charts use the same formula — confirm which version is current before citing a number from either.

## Golden Queries

**Negotiated wallet (Due Amount) and recovered amount (On Time Negotiation Recovery)**, by business day, trailing 12 months. Verbatim from production, validated in Trino (dry run).

```sql
SELECT
    business_day,
    dt_month_end,
    SUM(due_amount) AS "Due Amount",
    SUM(on_time_negotiation_installment_recovery) AS "On Time Negotiation Recovery"
FROM (
    SELECT * FROM sandbox.t2_fact_overdue_portfolio_timeline WHERE is_last_business_days = TRUE
) AS virtual_table
WHERE actionable_regularized_portfolio = TRUE
  AND status_evic IN ('EM COBRANCA') -- chart-specific refinement, not confirmed mandatory — see Canonical Filter note
  AND date_trunc('month', dt_reference) BETWEEN date_add('month', -12, date_trunc('month', current_date)) AND date_add('day', -1, current_date)
GROUP BY business_day, dt_month_end
ORDER BY dt_month_end DESC
```

**% Colchão Effectiveness** (recovered ÷ negotiated wallet), same population, by business day, trailing 12 months.

```sql
SELECT
    business_day,
    dt_month_end,
    SUM(on_time_negotiation_installment_recovery) * 1.0000 / SUM(due_amount) AS "% Colchão Effectiveness"
FROM (
    SELECT * FROM sandbox.t2_fact_overdue_portfolio_timeline WHERE is_last_business_days = TRUE
) AS virtual_table
WHERE actionable_regularized_portfolio = TRUE
  AND date_trunc('month', dt_reference) BETWEEN date_add('month', -12, date_trunc('month', current_date)) AND date_add('day', -1, current_date)
GROUP BY business_day, dt_month_end
ORDER BY dt_month_end DESC
```
