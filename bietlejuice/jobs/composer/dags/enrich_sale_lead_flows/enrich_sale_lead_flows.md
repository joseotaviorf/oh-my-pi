## Enrich Sale Lead Flows

### Purpose

Creates enriched tables for the context `sale_lead_flows`, enriching leads from Casa Mineira, Classifieds, Hub Services and Quinto Andar.

### Execution Interval

Daily. More information about run time [here]({chart_url}{dag_id}).

### Outputs

Produces the following output tables:
- `casa_mineira_lead_flow`
- `classified_lead_flow`
- `hub_services_lead_flow`
- `quintoandar_lead_flow`
