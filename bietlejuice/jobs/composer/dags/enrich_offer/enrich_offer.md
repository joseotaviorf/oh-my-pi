## Enrich Offer

### Purpose

Creates enriched tables for the context `Offer` enriching from ebdb, 
godfather and firestore.

### Execution Interval

Daily. More information about run time [here]({chart_url}{dag_id}).

### Outputs

Produces the following output tables:

- `offer`
- `sale_offer`
