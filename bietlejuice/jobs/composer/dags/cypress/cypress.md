## Cypress
### Purpose

Cypress is an End to End testing framework used by the product team here at Quinto Andar. This dag ingests the raw data (which is our test suite data), formats it and puts it in our data lake for the QAs to analyse.

### Execution Interval

Daily. More information about run time [here]({chart_url}{dag_id}).

### Outputs

Currently, there are the following output tables for both our raw and clean layers:

- `suites`
- `tests`
