## Enrich 3P
​
### Purpose
​
This DAG creates the enriched tables that filter agents and houses from the product 3P.
<details>
  <summary><strong> > DAG details (click to expand)</strong></summary>

### Execution​ Interval

This DAG is triggered once per day via Mediator.

More information about run time [here]({chart_url}{dag_id}).

### Outputs
​
This pipeline produces the following table in enrich layer, via full load:

- `agents_3p`
- `houses_3p`
- `houses_3p_bh`
