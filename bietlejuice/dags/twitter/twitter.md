## TWITTER
​
### Purpose
​
This DAG extracts marketing data from Twitter.
​
### Execution​ Interval

This DAG is trigged daily.

More information about run time [here]({chart_url}{dag_id}).

### Outputs
​
This pipeline produces the following output tables:

1. Data lake raw:
    - `twitter_campaigns`
    - `twitter_ad_groups`
    - `twitter_promoted_tweets`
    - `twitter_promoted_tweets_stats`
