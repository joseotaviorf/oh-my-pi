## Heimdall

### Purpose

This DAG extracts data from [Heimdall](https://github.com/quintoandar/heimdall), a financial hub to integrate the
payments related tasks into a contract life cycle.

### Execution Interval

This DAG is trigged daily.

More information about run time [here]({chart_url}{dag_id}).

### Outputs

This pipeline produces the following output tables:

1. Data lake raw:

    - activity

2. Data lake clean:

    - activity
