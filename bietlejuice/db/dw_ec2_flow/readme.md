This folder **dw_ec2_flow** contains some files that refer to tables of Redshift (DW) that might be still in use.
These files came from the old path `bietlejuice/db`, which contained the queries and DDLs used
by the EC2 flows. These files were all erased in the PR [#8429](https://github.com/quintoandar/bi-etl-ejuice/pull/8429), except for these kept in the dw_ec2_flow.
