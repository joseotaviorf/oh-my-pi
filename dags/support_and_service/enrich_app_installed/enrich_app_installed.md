## Enrich App Installed

### Purpose

Consolidate events related to usage of the QuintoAndar App per client.

### Execution Interval

This DAG is triggered once per day via Mediator. Please check the dependencies on `dependencies.yaml`

More information about run time [here]({chart_url}{dag_id}).

### Outputs

This pipeline produces the following output table on Enrich layer:

- `user_app_installed_event`
