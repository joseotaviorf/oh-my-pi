## Metric Rent Contracts

### Purpose

Rental contracts metrics, including active and ended, to get the information about the new rentals, new and ended contracts.

### Execution Interval

Daily. More information about run time [here]({chart_url}{dag_id}).

### Outputs

Currently, there is the following output table for both our raw and clean layers:

- `ended_rentals_confirmed_daily`
- `ended_rentals_confirmed_daily_by_sk_region`
- `ended_rentals_confirmed_monthly`
- `ended_rentals_confirmed_weekly`
- `new_contracts_signed_daily`
- `new_contracts_signed_daily_by_sk_region`
- `new_contracts_signed_monthly`
- `new_contracts_signed_weekly`
- `new_rentals_daily_by_sk_region`
- `new_rentals_daily`
- `new_rentals_monthly`
- `new_rentals_weekly`
- `new_tenant_prospect_to_contract_signed_4w`
