## Metric Rent Bookings

### Purpose

Rental bookings metrics, including TPs that made their first booking.

### Execution Interval

Daily. More information about run time [here]({chart_url}{dag_id}).

- `bookeds_weekly`
- `bookeds_weekly_by_sk_region`

- `new_bookers_daily_by_sk_region`
